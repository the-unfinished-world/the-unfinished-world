# The Unfinished World

Landing page for The Unfinished World, a collective of interdisciplinary thinkers and builders.

`index.html` is the site: one font, one size, plain paragraphs scrolling over a canvas scene in which a lone walker
climbs a zigzag of bridges up an ink-painted gorge. The scene is drawn live in `index.html` with `ink.js` (brush
washes, contours, pines, mist), `bridges.js` (rope suspension, timber truss, trestles on rock pinnacles, timber
cantilever), `walker8.js` (profile walker, male and female variants) and `brushfigure.js` (brush treatment).

Open `index.html` through any static server (fonts load from Google Fonts). `design/references/` holds the style
explorations, museum references, the review log and the stills behind every decision.
