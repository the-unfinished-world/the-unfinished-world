# The Unfinished World

Landing page for The Unfinished World, a collective of interdisciplinary thinkers and builders.

`index.html` is the site: one font, one size, plain paragraphs scrolling over a canvas scene in which a lone walker
climbs a zigzag of bridges up an ink-painted gorge. The scene is drawn live in `index.html` with `ink.js` (brush
washes, contours, pines, mist), `bridges.js` (rope suspension, timber truss, trestles on rock pinnacles, timber
cantilever) and `brushfigure.js` (brush treatment). The scroll moves the scenery with the text.

## The walker

The walker is built in three swappable layers, so one change reaches every character:

- `gait-clips.js`: the motion. Real walking strides from the CMU Graphics Lab Motion Capture Database
  (mocap.cs.cmu.edu; "may be copied, modified, or redistributed without permission"): level ground, a ramp and stairs,
  each a single looping stride seen from the side. Generated by `tools/gait/build_clips.py` from the downloaded
  `.asf`/`.amc` files, which also repairs glitched foot frames and smooths each swing (see the script's notes).
  To add or swap a clip, add it to `CLIPS` there and rebuild.
- `rig.js`: the player. Blends the clips by deck slope, loops them, fits each stride to the deck and returns a pose
  (every joint, in body heights). It knows nothing about bodies.
- `bodies.js`: the characters. A body is plain data on that pose: limb widths, torso outline, head, hair and
  headwear, garments that hang to a hem between the legs, and props (staff, sword, shield, lantern...).
  `TUWBodies.archetypes` (philosopher, sage, wanderer, swordsman, barbarian, athletes, pilgrim, hoplite, scribe,
  lantern bearer, shepherd, oracle) and `TUWBodies.variants` (everyday walkers) are made with `TUWBodies.make(spec)`.
  Proportions are per body: height, build, head size, upper-body length against the legs, stoop.

Visitors see a random character on each crossing; a signed-in member walks as the character chosen in their
profile (`figure` in the members table, see `supabase/003_characters.sql`). `walker7.js`/`walker8.js` remain as
the fallback procedural walker.

Open `index.html` through any static server (fonts load from Google Fonts). `design/references/` holds the style
explorations, museum references, the review log and the stills behind every decision.
